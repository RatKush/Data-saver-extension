# Store listing assets

| File | What it is |
|---|---|
| `description.md` | Paste into the Chrome Web Store "Description" field. |
| `permission-justifications.md` | Paste into the dashboard's "Privacy practices" tab. |
| `publisher-page.md` | Publisher profile copy. |
| `screenshots/` | Generated by `scripts/make-screenshots.py` from the shipping code. Three 1280×800 frames. |

**The privacy policy lives at `docs/privacy-policy.html`**, not here — GitHub Pages can only serve from the repository root or `/docs`, and the Chrome Web Store listing needs a public URL for it. Keeping one copy rather than a copy per location is deliberate: a duplicate would drift, and this is the document that has to stay true.

Once Pages is enabled for this repo it is served at:
`https://ratkush.github.io/Data-saver-extension/privacy-policy.html`
