# Store listing assets

| File | What it is |
|---|---|
| `description.md` | Paste into the Chrome Web Store "Description" field. |
| `permission-justifications.md` | Paste into the dashboard's "Privacy practices" tab. |
| `publisher-page.md` | Publisher profile copy. |
| `screenshots/` | Generated by `scripts/make-screenshots.py` from the shipping code. Three 1280×800 frames. |

**The privacy policy lives at `docs/privacy-policy.html`**, not here. The Chrome Web Store requires a public URL for it, and `docs/` is a directory that can be published as a site root on its own — so the policy gets a clean URL without the rest of the repository being served alongside it.

Host it on **Cloudflare Pages**, the same as the sibling ad-blocker project: point a Pages project at this repo with the build output directory set to `docs`, and the policy is served at `<project>.pages.dev/privacy-policy.html`. Free, no domain needed, and a custom domain can be attached later without moving anything.

Keeping one copy rather than a copy per location is deliberate: a duplicate would drift, and this is the document that has to stay true.

**Once the URL exists, put it in two places:** the Chrome Web Store dashboard's privacy policy field, and the `[link]` placeholder at the end of `description.md`.
